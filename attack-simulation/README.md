# ⚔️ Attack Simulation

## 📖 Overview

This folder documents the attack simulation activities performed to generate security events for validation and analysis in the Wazuh SIEM environment.

The simulations were conducted from a Kali Linux virtual machine against the monitored Ubuntu endpoint.

---

## 🧪 Simulated Activities

The following activities were performed during the project:

- Failed SSH login attempts
- Successful SSH login events
- File Integrity Monitoring (FIM) testing
- Custom log generation using `DEMO-SECURITY`

---

## 🎯 Purpose

These simulations were used to:

- Validate custom detection rules
- Generate security alerts
- Verify File Integrity Monitoring (FIM)
- Practice threat hunting using the Wazuh Dashboard
